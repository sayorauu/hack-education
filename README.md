# NASstudy 🐾 — v2

AI-репетитор для 7–9 классов: **математика** (алгебра, геометрия) и **қазақ тілі — оқу сауаттылығы**. Интерфейс на казахском и русском, светлая и тёмная тема. Наставник — капибара **Капи**, логотип — медведь с книгой (`logo-bear.png`): в тёмной теме он автоматически становится белым.

## Что внутри

| Раздел | Что делает |
|---|---|
| Главная | Прогресс (решено / % верных / освоение по предметам, PISA), активность класса, рекомендуемые темы, календарь занятий, план на день |
| Темы | 28 тем (20 по математике, 8 по чтению), поиск сразу на двух языках, фильтры по предмету и классу |
| Практика | 84 задания с подсказками и разборами; чтение — с текстами и таблицами на казахском |
| Капи (AI) | «Умный» режим: Gemini → нейросеть на устройстве → разбор из учебника. Под каждым ответом метка, кто ответил |
| Пробный PISA | 12 заданий (6 математика + 6 чтение), примерный балл, уровень PISA, сравнение со средним по Казахстану и ОЭСР |
| Рейтинг | «Больше всех решил» и «Самый точный» (от 20 заданий), пьедестал |
| Кошелёк | Монеты за учёбу и **демо**-обмен на тенге с анимацией и квитанцией |

## Запуск на компьютере (Mac)

Двойной клик по **`start-nasstudy.command`**. Откроется http://localhost:8091.

## Ключ Gemini

Ключ хранится только на сервере и в браузер не попадает.

- **На своём компьютере:** откройте файл `.env` и замените `ВСТАВЬТЕ_СЮДА_КЛЮЧ` своим ключом. Ключ берут в aistudio.google.com → Get API key. Затем перезапустите `start-nasstudy.command`.
- **На Vercel:** Project → Settings → Environment Variables → `GEMINI_API_KEY`, затем Redeploy.
- Модель по умолчанию `gemini-3.5-flash-lite`. Более сильная — `GEMINI_MODEL=gemini-3.8-flash`.
- Проверка: http://localhost:8091/api/config должен показать `"tutor": true`, а под ответом Капи — «Ответил ИИ Gemini».

`.env` указан в `.gitignore`, в git он не попадёт. Не публикуйте его.

## Важно знать

- **Монеты → тенге — только демо.** Настоящих переводов нет. Для реальных выплат детям нужны договор с банком или платёжным сервисом, согласие родителей и юридическая проверка. Логотипы реальных банков намеренно не используются.
- **Пробный PISA** — ориентир, а не официальный балл. Задания оригинальные, в стиле PISA. Шкала задана заранее: вес верных ответов по уровням переводится в 300–650. Средние баллы — PISA 2025 (ОЭСР, сентябрь 2026): Казахстан — математика 414, чтение 385; ОЭСР — математика 463, чтение ≈462.
- **Рейтинг** пока показывает демо-одноклассников. Настоящий рейтинг класса требует общего сервера с аккаунтами.
- **Темы** составлены по структуре учебников обновлённого содержания РК. Официальные типовые программы найти в открытом доступе не удалось, поэтому перед использованием в школе стоит сверить их с учителем.
- **Нейросеть на устройстве** (WebLLM, Qwen3.5) скачивается один раз (~1,1 ГБ) и работает без интернета. Нужен браузер с WebGPU.

Предыдущая версия сайта сохранена в папке `../nasstudy-v1-backup`.

## Новый ученик

При первом входе: язык → имя → класс (3 шага), затем короткий тур из 8 шагов (можно пропустить, повторить — «Профиль → Посмотреть тур снова»). Никаких выдуманных данных: прогресс, активность и рейтинг начинаются с нуля и заполняются только тем, что ученик сделал сам.

## Что Капи знает об ученике

С каждым вопросом в Gemini (и в нейросеть на устройстве) уходит профиль: имя, класс, язык, решено/верно/точность, серия дней, монеты, освоение по предметам и изученным темам, слабые темы, 3 последние ошибки с верными ответами, задание, которое ученик решал в последние 30 минут, результат пробного PISA. Формирует его `studentContext()` в `src/engine/tutor.js`; на сервере — `studentBlock()` в `api/tutor.js` и `student_block` в `server.rb`. Имя ученика при этом передаётся в Google Gemini.

## Как это работает без интернета

1. **Сайт** после первого открытия сохраняется в браузере (service worker `sw.js`) и потом открывается без сети.
2. **Прогресс, монеты, результаты** хранятся в этом браузере (localStorage) — интернет для них не нужен.
3. **Капи** выбирает лучший доступный вариант: есть интернет и ключ → Gemini; нет интернета → нейросеть на устройстве (Qwen3.5, ~1,1 ГБ, скачать один раз по Wi-Fi на странице Капи; нужен браузер с WebGPU); нет и её → готовый разбор из учебного графа. Под ответом всегда видно, кто ответил.
4. Без интернета не работают только Gemini и админка (ей нужен сервер для проверки PIN).

## Админка

«Профиль → Админ» (или адрес `#/admin`). Вход по PIN-коду, который проверяет сервер: `ADMIN_PIN` в `.env` (уже создан случайный, можно заменить) или в переменных Vercel. После 5 неверных попыток — пауза 60 секунд. Можно быстро добавить +50…+1000 монет, ввести свою сумму (минус — списать) с причиной, обнулить монеты. Все изменения видны в истории с пометкой «Админ». Пока общего сервера с аккаунтами нет, монеты начисляются ученику на этом устройстве.
